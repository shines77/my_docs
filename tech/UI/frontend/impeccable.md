## 安装

```bash
npx skills add pbakaus/impeccable
```

执行后，可以选择要安装的命令(skill)。

然后选择要安装的 Coding Agent 。

## 使用

How Impeccable works：

```bash
/impeccable <command> <target>
```

命令：

| Command | What is does |
| ------- | ------------ |
| `/impeccable craft` | 先设计好，再创建，一气呵成。 |
| `/impeccable shape` | 在动手之前先思考，通过探索发现，而非凭空猜测，来制定设计纲要。 |
| - | - |
| `/impeccable audit` | 执行技术质量检查（无障碍、性能、响应式） |
| `/impeccable critique` | 包含评分、人物角色测试和自动检测的设计评审。 |
| - | - |
| `/impeccable animate` | 有目的的动作，传达状态，而非装饰。 |
| `/impeccable bolder` | 推动安全设计以应对冲击，同时避免陷入混乱。 |
| `/impeccable colorize` | 在不显得花哨的情况下，为单色界面增添战略性色彩。 |
| `/impeccable delight` | 小小的个性瞬间，让功能变得令人难忘。 |
| `/impeccable layout` | 调整布局、间距和视觉节奏 |
| `/impeccable overdrive` | 将界面推向传统极限。着色器、物理效果、60帧、电影级过渡。 |
| `/impeccable quieter` | 在不失去原意的前提下，降低那些过于张扬的设计的调性。 |
| `/impeccable typeset` | 调整字体选择、层级结构、尺寸大小 |
| - | - |
| `/impeccable adapt` | 让设计在各种屏幕、设备和情境下都能适用，同时不牺牲任何功能。 |
| `/impeccable clarify` | 重写令人困惑的用户体验文案，让界面自我解释。 |
| `/impeccable distill` | 无情删减。将设计精简至其本质。 |
| - | - |
| `/impeccable harden` | 使接口达到生产就绪状态。处理边缘情况、国际化（i18n）、错误状态和溢出问题。 |
| `/impeccable onboard` | 设计首轮体验、空状态和价值路径。 |
| `/impeccable optimize` | 从LCP到包大小，诊断并修复用户界面性能问题。 |
| `/impeccable polish` | 最终审核、设计系统对齐以及发货准备 |
| - | - |
| `/impeccable document` | 生成一个符合规范的DESIGN.md文件，在其中详细描述你的视觉系统，<br/>以确保每个AI代理都保持品牌一致性 |
| `/impeccable extract` | 将可重复使用的组件、标记和模式纳入设计系统中。 |
| `/impeccable live` | 在浏览器中对用户界面（UI）进行迭代。选择一个元素，添加一条注释，<br/>即可得到三个变体。选择其中一个，它就会写入源代码。 |
| `/impeccable teach` | 在每个项目中，向Impeccable说明你的产品是为谁服务的。 |

Usage Examples：

```bash
/impeccable audit blog           # Audit blog hub + post pages
/impeccable critique landing     # UX design review
/impeccable polish settings      # Final pass before shipping
/impeccable harden checkout      # Add error handling + edge cases
```

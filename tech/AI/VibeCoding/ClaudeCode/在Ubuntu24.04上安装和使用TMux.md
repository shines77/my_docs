# 在 Ubuntu 24.04 上安装和使用 TMux

## 1. TMux 的安装

你遇到的界面差异，根源在于 `screen` 这个老牌工具对现代终端特性的支持有限。它很可能无法正确传递颜色、鼠标事件，甚至会导致 `opencode` 这类 TUI 程序出现渲染错误。**不建议继续用 `screen` 来跑这些工具**，换用 `tmux` 或直接利用 WezTerm 自带的多路复用功能，是更彻底的解决办法。

### 为什么 `screen` 会导致界面异常

`opencode` 和 `claude code` 这类现代命令行工具，依赖终端提供完整的色彩（如 256 色或真彩色）和特定的控制序列来绘制界面。

*   **`opencode` 的兼容性问题**：`opencode` 的底层渲染库在检测到 `screen` 或 `tmux` 环境时，发送的图形能力探测请求可能会出错，导致乱码或渲染异常。
*   **`claude code` 的降级渲染**：`claude code` 在检测到终端能力不足时（例如通过 SSH 连接且 `TERM` 变量设置不当时），会自动降级为更简单的“经典渲染器”，这与你直接连接时看到的“全屏渲染器”界面完全不同。

### 推荐方案：用 `tmux` 替代 `screen`

`tmux` 是 `screen` 的现代替代品，对现代终端特性的支持好得多。`claude code` 官方文档也明确提到了与 `tmux` 的兼容性，并给出了优化建议。

1.  **在 Ubuntu 上安装 `tmux`**：

    ```bash
    sudo apt update && sudo apt install tmux
    ```

2.  **关键配置（针对 `claude code`）**：为了让鼠标滚轮和界面渲染正常，需要在 `~/.tmux.conf` 中开启鼠标支持。

    ```bash
    vim ~/.tmux.conf
    
    # 编辑 ~/.tmux.conf，加入下面这行
    set -g mouse on
    ```

    然后重新加载配置：`tmux source-file ~/.tmux.conf`。

3.  **使用方式**：连接服务器后，运行 `tmux`，然后在其中启动 `opencode` 或 `claude code`。如果遇到画面错乱，可以按 `Ctrl+L` 强制重绘。

### 备选方案：使用 WezTerm 自身的持久化会话

如果你追求网络断开后会话不丢失，又不想在服务器上装 `tmux`，可以尝试 WezTerm 的 **SSH Domain** 功能。

这需要你在**本机**和**Ubuntu 服务器**上都安装 WezTerm（服务器端仅作为后台守护进程，无需图形界面）。配置好后，用 `wezterm connect 你的域名` 连接，会话就能在本地网络波动时保持。但考虑到你之前已经在服务器版上遇到过安装图形程序的困扰，这个方案的配置成本稍高。

### 如果问题依旧（针对 Claude Code）

如果换了 `tmux` 后，`claude code` 的界面颜色或字符仍有异常，可以尝试在启动时显式指定终端类型，强制它使用更丰富的色彩：

```bash
TERM=xterm-256color claude
```

或者，如果界面闪烁或有其他渲染 bug，可以尝试社区提供的 `claudefix` 包装工具（`npm install -g claudefix`，然后使用 `claude-fixed` 命令）。不过，优先建议你先试 `tmux` 方案，这通常能解决大部分问题。

## 2. TMux 的使用

tmux 的核心用法不复杂，记住“前缀键 + 功能键”这个模式就行。默认的前缀键是 `Ctrl+b`，所有快捷键都要先按它，松开后再按功能键。

### 启动与恢复会话

这是你通过 SSH 连接后最先要用到的命令。

*   **新建会话**：在终端直接输入 `tmux`，或者给它起个名字方便以后找回：`tmux new -s 你的会话名`。
*   **暂时离开（Detach）**：在 tmux 里按 `Ctrl+b` 然后按 `d`。这样会话会在后台继续运行，你正在跑的 opencode/claude code 不会中断。
*   **重新连接（Attach）**：下次连上服务器后，输入 `tmux a -t 你的会话名` 就能回到之前的工作现场。

### 开新窗口（Window）

如果你需要在同一个会话里同时跑多个任务（比如一个窗口跑 claude code，另一个查日志）。

*   **新建窗口**：按下 `Ctrl+b`，松开，然后按 `c`。
*   **切换窗口**：`Ctrl+b` 然后按 `n`（下一个）或 `p`（上一个）。也可以用数字键直接跳转，比如 `Ctrl+b` 然后按 `0` 或 `1`。
*   **关闭窗口**：`Ctrl+b` 然后按 `&`（会提示你确认）。

### 分屏（Pane）

如果你想把一个窗口拆成几块，一边看代码一边看运行结果。

*   **左右分屏**：`Ctrl+b` 然后按 `%`。
*   **上下分屏**：`Ctrl+b` 然后按 `"`。
*   **在分屏间切换**：`Ctrl+b` 然后按 **方向键**（上下左右）。
*   **关闭当前分屏**：`Ctrl+b` 然后按 `x`（确认即可），或者直接输入 `exit`。

### 你之前关心的：开启鼠标支持

针对你之前遇到的 Claude Code 界面问题，**务必先开启鼠标模式**，否则滚轮可能无法滚动或者会被程序捕获。

在 `~/.tmux.conf` 文件里加上这一行：

```bash
set -g mouse on
```

保存后，在 tmux 里执行 `tmux source-file ~/.tmux.conf` 让它生效。之后你就能用鼠标滚轮翻看历史输出，或者点击切换分屏了。

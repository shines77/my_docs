# 宝塔面板的关闭与使用

要只保留宝塔App登录、关闭网页版面板登录，目前没有官方提供的一键开关能精确做到“只禁用网页、不禁用App”。现有可行思路是停掉面板的Web访问服务，这样网页端自然无法登录，但宝塔App同样依赖面板Web服务，因此也会一起失效。

⚠️ 关键限制

- 宝塔App（堡塔APP）本质上是通过面板的Web接口进行远程管理，并非独立于面板的服务。关闭网页版登录入口，App端同样会无法连接服务器。
- 目前官方文档和社区方案中，没有找到能单独关闭网页端登录、同时保留App登录的配置项或命令。

✅ 如果仍想关闭网页版登录

可以SSH到服务器执行以下操作，但这会同时影响App：

1. 停止面板服务（网页和App都无法访问）

   ```bash
   bt 2
   ```

   或

   ```bash
   /etc/init.d/bt stop
   ```

   此操作不影响Nginx、PHP、MySQL等网站服务的运行。

2. 恢复面板服务

   ```bash
   bt 3
   ```

   或

   ```bash
   /etc/init.d/bt start
   ```

💡 替代方案

如果你担心的是网页端被他人暴力破解或扫描，建议改用以下方式加强安全，而不是关闭网页登录：

- 修改面板端口：`bt 8`（推荐改为非8888的高位端口）
- 修改安全入口：`bt 28`（设置复杂的8位以上入口路径）
- 开启IP访问限制：`bt 13` 相关命令，只允许你的固定IP访问
- 开启动态口令认证：在面板【设置→安全设置→动态口令】中开启，然后用堡塔App扫码绑定，这样即使网页登录也需要App生成的30秒动态口令

如果你确实需要“网页端完全不可登录”，目前只能通过停掉面板服务实现，但App也会随之失效，需要恢复时再执行启动命令即可。
